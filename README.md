# Cybersecurity Portfolio — Starter Website

A responsive personal portfolio starter built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive styles, colors, and visual details
- `script.js` — mobile navigation, current year, and starter project-link behavior

## Run locally
1. Extract the ZIP file.
2. Open the `cybersecurity-portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit the name, bio, skill descriptions, projects, and contact links before publishing.

## Important before publishing
- Replace placeholder LinkedIn and GitHub URLs with your real profile links.
- Update the skills section so it accurately reflects what you can currently demonstrate.
- Change project labels from `PLANNED` to `COMPLETED` only after finishing the work.
- Link each project to a real repository or write-up when available.
- Use only systems you own or have explicit permission to test.

The page loads Google Fonts from the internet. It still works if you are offline, but it will use fallback fonts.
